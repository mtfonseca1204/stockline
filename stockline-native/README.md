# Stockline (Native)

Self-repaying credit for tokenized stocks on Base — Expo / React Native app.

Highlight color: **lime** (`#A8E10C`). Logo mark is a temporary “S” placeholder.

## Run

```bash
cd stockline-native
npm start
```

Then press:
- `a` for Android emulator / device
- `i` for iOS simulator
- `w` for Expo web preview (optional)

## Demo Mode

On the landing screen tap **Skip ahead — enter Demo Mode**.

Dashboard presenter controls:
- **+10% growth**
- **Generate $100 yield** (auto-repay reduces debt)
- **Empty state**

## Tabs

Dashboard · Portfolio · Credit · Activity
